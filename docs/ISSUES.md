# Reporting an Issue

Found a bug, hardware problem, or something that isn't working as expected?

Before opening an issue:

* Check whether the issue has already been reported.
* Make sure you're using the latest available version.
* Try to reproduce the problem if possible.

## Include

Please provide as much of the following information as you can:

* **What happened?**
* **What did you expect to happen?**
* **How can it be reproduced?**
* **Hardware / firmware version**, if relevant
* **Photos, videos, logs, or screenshots**, if useful

You don't need to have all the information before reporting an issue. If you're unsure about the cause, just describe what you observed.

## Example

```text
Title: Display becomes blank after returning from Dino

What happened:
The display goes blank when returning to the menu.

Expected:
The menu should appear normally.

Steps:
1. Open Dino
2. Exit the game
3. Return to the menu

Hardware: EBadge Rev 1
Firmware: <commit>

Photo/video: attached
```

## Keep Issues Focused

Try to report one problem per issue.

If you discover more information later, you can add it to the existing issue.
